KI-Modell

  1. Nur Chrome oder Edge (aktuell) auf PC oder Android – kein Firefox/Safari.
  2. Prüfen: chrome://gpu öffnen, bei „WebGPU“ muss Hardware accelerated stehen. Sonst unter Einstellungen → System „Hardwarebeschleunigung“ einschalten und Browser neu starten.
  3. Modell wählen (Faustregel: Dein Grafikspeicher sollte größer als die GB-Angabe sein) und auf Jetzt laden klicken. Der Download läuft nur einmal.
  4. Fehler „kein GPU“ oder „f16“? Ein Modell mit f32-Variante probieren – oder einen anderen Anbieter wählen.

Läuft komplett auf deinem Gerät, kein Key nötig. Der Download passiert einmalig und bleibt im Browser gespeichert. Braucht Chrome/Edge mit WebGPU. PDFs, Word, Excel, Text und Bilder werden im Browser ausgelesen (PDF-Text direkt, gescannte PDFs und Bilder per OCR – dafür wird beim ersten Mal ein Texterkennungs-Paket geladen).

  1. ollama.com/download installieren (Windows, Mac, Linux).
  2. Ollama für Browser-Zugriff freigeben: Windows: Systemumgebungsvariable OLLAMA_ORIGINS = * setzen. Mac: launchctl setenv OLLAMA_ORIGINS "*". Linux: OLLAMA_ORIGINS=* ollama serve. Danach Ollama neu starten.
  3. Im Terminal ein Modell laden, z. B. ollama pull gemma3:4b.
  4. Unten Modellnamen auswählen (genau wie bei ollama list) und Speichern.
  5. LM Studio statt Ollama? Dann „Weitere Anbieter“ → „LM Studio“ wählen.

Ollama (ollama.com) oder LM Studio auf deinem PC starten, ein Modell laden (z. B. ollama pull gemma3:4b, kann auch Bilder sehen). Damit der Browser zugreifen darf, Ollama mit der Umgebungsvariable OLLAMA_ORIGINS=* starten. PDFs werden im Browser zu Text gelesen, Bilder gehen direkt ans Modell.

  1. aistudio.google.com/apikey öffnen und mit Google-Konto anmelden.
  2. „API-Schlüssel erstellen“ klicken und den Key (beginnt mit AIza) kopieren.
  3. Unten einfügen, Modell wählen, Speichern. Neuestes Modell: gemini-3.8-flash (schnell, gut für Dokumente). Pro-Modelle sind genauer, im Gratis-Tarif aber stärker limitiert oder nur mit Abrechnung nutzbar. Mit gemini-flash-latest bekommst du automatisch immer das aktuelle Flash-Modell. Meldet Google „Modell nicht gefunden“, den Namen unter ai.google.dev/gemini-api/docs/models nachsehen.

Kostenloser Key: aistudio.google.com → „Get API key". Achtung: Im kostenlosen Tarif dürfen Google-Dienste die Eingaben ggf. zur Verbesserung nutzen – keine privaten Daten hochladen. PDFs und Bilder liest Gemini direkt. Der Key bleibt nur in diesem Browser.
